# AeroMind — site oficial

Projeto web em Next.js + TypeScript hospedado na Vercel. Layout escuro e roxo inspirado no aplicativo AeroMind Monitor.

## Entrega atual
- Página inicial responsiva, recursos B4/Rosa, histórico visual e FAQ.
- Rotas informativas de cadastro, login, download, conta, termos, privacidade e contato.
- Fluxos de pagamento e criação de conta **não habilitados** nesta etapa; o site não recebe dados nem cobranças.
- Valores e interfaces do dashboard ilustram o produto, sem alegações de win rate ou retorno garantido.

## Próximas integrações
- Supabase Auth, RLS e licenças.
- Pagamentos e webhook após escolher provedor e planos.
- Download de APK assinado e bloqueio efetivo no app Android existente.
- Documentos jurídicos revisados antes de aceitar pedidos.

## Desenvolvimento
`npm install && npm run build`.

**Atenção:** ainda requer teste de build na Vercel e testes completos antes de declarar o sistema pronto para venda.
