# AeroMind V2 — landing visual aprovada

- Layout responsivo de referência: hero duas colunas no desktop, painel de demonstração, seis cards neon, histórico/indicadores, galeria com capturas do aplicativo, três modalidades de plano sem preços, FAQ e rodapé.
- Capturas originais apresentadas como miniaturas em um sprite otimizado para site.
- W/L e multiplicadores demonstrativos não são resultados auditados e não implicam garantia.
- Cadastro, login, licenças, pagamentos e download protegido NÃO estão implantados nesta versão.
- O Next.js lê o template estático `app/landing.html` durante a renderização de `app/page.tsx` e carrega o CSS `public/design-v2.css`.
- Após mudanças, validar build e navegação antes de promover a produção.
